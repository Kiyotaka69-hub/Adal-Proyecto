# MoneyTrack
Aplicación Android de finanzas personales en desarrollo. El alcance incluye ingresos, gastos, categorías privadas, presupuestos mensuales y predicción local. La arquitectura prevista conecta Expo con una API .NET 8 y SQL Server.
 
Consulta [los requisitos](docs/REQUISITOS.md), [el plan](docs/PLAN_DESARROLLO.md) y [el estado de las verificaciones](docs/PROGRESO.md).
